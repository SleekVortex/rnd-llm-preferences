# Дополнительные проверки ДЗ2

У прежнего BERT после одной эпохи log loss на train 1,07277, на validation 1,08543. Обе оценки получены с выключенным dropout. Внешние результаты ДЗ2 уже известны. Это продолжение исследования на том же разбиении.

| Проверка | Что меняем | С чем сравниваем |
|---|---|---|
| 1.1 | Для mBERT выбираем одну из эпох 2, 3, 4 | Первая эпоха того же обучения |
| 1.2а | RoBERTa-large | mBERT, для обоих выбор эпохи из 1–4 |
| 1.2б | ModernBERT-large | То же сравнение |
| 2.1 | LoRA на PairJudge, выбираем эпоху 1 или 2 | Те же веса до адаптации |

Внутри 6795 обучающих диалогов берем первый fold StratifiedGroupKFold, 5 частей, seed 42. Группа объединяет одинаковые первые запросы или пары ответов по всему исходному датасету. Эпоху выбираем по наименьшему внутреннему log loss, при равенстве берем более раннюю. После выбора начинаем обучение заново на всем доступном train. Внешний набор открываем для итоговой оценки.

У энкодеров одинаковые разбиение, AdamW, lr 0,00002, weight decay 0,01, эффективный батч 64 и лимиты 96/206/206 токенов. Каждый использует свой токенизатор. Сравниваем готовые архитектуры с их предобучением. Размер, язык и корпус меняются вместе. У PairJudge сохраняем родную упаковку и порядок классов. Для дообучения и внутренней проверки исключаем группы из опубликованных разбиений судьи. Обучаем адаптеры q_proj и v_proj с рангом 8, alpha 16 и классификационную голову, lr 0,0001. У ArenaJudge возможны пересечения с тестом, доступная версия представляет собой ONNX для инференса.

Внешняя проверка энкодеров использует 1699 пар без связи с train. Для судьи берем те же 512 групп, что в ДЗ2. Меньший multiclass log loss лучше. Для четырех сравнений строим парные интервалы 98,75% по связанным группам, 10 000 выборок с seed 42. Верхняя граница ниже нуля означает выигрыш в этом сравнении. Интервалы описывают разброс примеров на знакомом holdout. Отдельно сравниваем каждую модель с TF-IDF на тех же строках.
