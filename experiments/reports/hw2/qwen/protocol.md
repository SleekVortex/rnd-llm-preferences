# Проверка Qwen3

Три варианта: Qwen3-1.7B + LoRA, Qwen3-4B + LoRA, полный fine-tuning Qwen3-1.7B. Один запрос и два ответа подаем в исходном порядке. Новая голова предсказывает A, B или ничью по последнему токену. Имена авторов ответов в признаки не входят.

Все модели обучаем на одних 5352 парах. Для подбора сохраняем внутреннее разбиение ДЗ2: 4282 строки для обучения, 1070 для выбора. Эпохи 1 и 2, для LoRA проверяем lr 0,00005 и 0,00015, для полного обучения 0,000005 и 0,000015. Выбираем минимальный внутренний log loss, при равенстве более раннюю эпоху и меньший lr. Затем заново обучаем на всех 5352 парах.

У всех один seed 42, эффективный батч 64, AdamW, weight decay 0,01, ограничение нормы градиента 1. Вход до 512 токенов: до 96 для запроса и по 192 для каждого ответа плюс служебный текст. У LoRA ранг 16, alpha 32, адаптеры на q_proj и v_proj. У трех моделей обучается классификационная голова. В обоих вариантах 1.7B ее начальные веса совпадают. Для полного fine-tuning обновляем все параметры.

Основная оценка использует 717 групп вне прежней панели из 512. Отдельно проверяем те же модели на старой панели. Выбираем одну пару по хешу ID на группу, исключаем связи с train и опубликованными выборками PairJudge. Это данные того же источника, ранее использованные в общей оценке энкодеров.

Основная метрика multiclass log loss. Каждый вариант сравним с TF-IDF, обученным на тех же 5352 парах, и с прежним TF-IDF на 6795. Для шести парных разниц берем интервалы 99,17% с поправкой Бонферрони, 10 000 bootstrap-выборок групп, seed 42. Верхняя граница ниже нуля означает выигрыш против данного бейзлайна. Для двух дополнительных сравнений размера и способа обучения считаем интервалы 97,5%. Accuracy и macro-F1 справочные.
